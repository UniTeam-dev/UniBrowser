# UniBrowser для iPhone

iOS-версия UniBrowser: обычный браузер и режим «Через Mac». В режиме «Через Mac»
вкладки, группы и пространства — это вкладки вашего Mac (живое зеркало в обе
стороны), сохранённые пароли приходят с Mac, а рабочие домены открываются через
сеть Mac и его корпоративный VPN. Работает из любой сети. Дизайн:
[UniBrowser для iPhone: режим «через Mac»](https://claude.ai/code/artifact/8b6929b1-d069-4f62-94e8-03ab18dca5fd).

## Сборка

Нужны Xcode 16+ и iOS 17.5+.

```sh
mobile/build.sh                     # симулятор, без подписи; лог в mobile/build.log
# или
cd mobile && xcodegen generate && open UniBrowserMobile.xcodeproj
```

Для iPhone выберите свою команду в Signing & Capabilities (подойдёт бесплатный
Apple ID) и запустите. `mobile/build-device.sh` собирает ad-hoc `.ipa` для своего
телефона, `mobile/build-device.sh appstore` — `.ipa` для App Store Connect; что
нужно для подачи, см. [docs/app-store.md](../docs/app-store.md).

## Как связать с Mac

1. На Mac в UniBrowser: меню «Вкладки» → «iPhone…» (⇧⌘I), включите «Связь с iPhone»,
   нажмите «Показать QR-код».
2. Наведите камеру iPhone на код и откройте ссылку в UniBrowser (или скопируйте код
   на Mac и вставьте в «Настройки «Через Mac»» на телефоне).
3. В настройках «Через Mac» добавьте рабочие домены, например `corp.example`.

Mac должен быть включён и не спать; пока связь включена и есть сопряжённый iPhone,
UniBrowser не даёт ему уснуть по бездействию.

## Что умеет

- Браузер с адресом и кнопками внизу; вкладки засыпают, когда не на экране.
- Пространства, закреплённые вкладки, группы-папки и «Сегодня», как в боковой панели на Mac.
- Два режима со своими вкладками, cookie и историей; переключение в меню «…».
- «Обычный»: самостоятельный браузер, ничего не синхронизирует.
- «Через Mac»:
  - Зеркало вкладок. Пока есть связь, открытие, закрытие, перенос в группу и
    переход по ссылке сразу видны на другой стороне. Без связи телефон работает со
    своей копией; при подключении Mac объединяет обе стороны: побеждает более позднее
    изменение, новые вкладки с обеих сторон сохраняются, закрытые остаются закрытыми.
  - Прокси. WKWebView отправляет рабочие домены в SOCKS5 на 127.0.0.1:47801, оттуда
    по туннелю iroh (напрямую или через реле, сквозное шифрование) на Mac, который
    сам резолвит имена и ходит в сеть через свой VPN. Отката на прямое соединение нет.
  - «Открыть на Mac»: текущая страница открывается новой вкладкой на Mac.
- Пароли в обоих режимах: «Войти как …», когда для сайта есть сохранённый пароль, и
  «Сохранить пароль?» после входа. Пароли UniBrowser с Mac приходят при каждом
  подключении, сохранённые на телефоне уходят на Mac. Хранятся в Keychain телефона.
- «Стереть данные режима» удаляет копию вкладок, пароли с Mac, cookie и кэш на телефоне;
  на Mac ничего не удаляется.

## Устройство связи

Общий код лежит в `../Shared/ViaMac` и компилируется в оба приложения:
`ViaMacProtocol.swift` (форматы), `ViaMacTransport.swift` (потоки iroh, SOCKS-труба,
кадры синхронизации), `SessionMerge.swift` (объединение сессий; проверка —
`scripts/merge_check.swift`, см. README в корне). Формат сессии —
`../UniBrowser/Models/SessionSnapshot.swift`, тот же файл, что Mac пишет на диск.

Каждый поток iroh начинается с байта вида: 1 — SOCKS5, 2 — один управляющий запрос
(сопряжение, «Открыть на Mac»), 3 — синхронизация: кадры «длина + JSON» в обе стороны
(`hello` с базой последнего согласия → ответ Mac с объединённой сессией и паролями →
дальше `session` при каждом изменении).
