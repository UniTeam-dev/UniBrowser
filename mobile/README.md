# UniBrowser для iPhone

iOS-версия UniBrowser: обычный браузер и режим «Через Mac», в котором рабочие
домены открываются через ваш Mac и его корпоративный VPN. Дизайн:
[UniBrowser для iPhone: режим «через Mac»](https://claude.ai/code/artifact/8b6929b1-d069-4f62-94e8-03ab18dca5fd).

## Сборка

Нужны Xcode 16+ и iOS 17+.

```sh
cd mobile
brew install xcodegen   # если ещё не стоит
xcodegen generate
open UniBrowserMobile.xcodeproj
```

Выберите свою команду в Signing & Capabilities и запустите на iPhone или в симуляторе.

## Что есть на этапе 1

- Браузер с адресом и кнопками внизу, вкладки засыпают, когда не на экране.
- Пространства, закреплённые вкладки, группы-папки и «Сегодня», как в боковой
  панели на Mac. Модель `Space`/`TabGroup` общая с macOS (`../UniBrowser/Models/Space.swift`).
- Два режима со своими вкладками, cookie и историей; переключение в меню «…».
- Режим «Через Mac»: отдельное хранилище сайта, список рабочих доменов и
  настройка прокси WKWebView (SOCKS5 на 127.0.0.1:47801 только для этих доменов,
  без отката на прямое соединение). Кнопка «Стереть данные режима».
