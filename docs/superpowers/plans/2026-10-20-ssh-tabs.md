# SSH Tabs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A tab can be an SSH server: terminal after login, SFTP files panel, command suggestions; hosts and keys live in the vault and sync with the iPhone, which connects directly or through the Mac.

**Architecture:** Platform-free model and network code in `Shared/SSH/` (compiled into both apps): host store with keychain secrets, known hosts, keys, `SSHSession` on Citadel, `SFTPBrowser`, `CommandLineModel` and `SuggestionEngine`. Each app adds its views on SwiftTerm. An SSH tab is an ordinary tab with URL `unibrowser-ssh://<host-uuid>`, so sessions, spaces and the mirror carry it unchanged. Hosts and known hosts sync as two new `SyncMessage`s on protocol `/3`.

**Tech Stack:** Swift 6, SwiftUI, Citadel 0.12.1 (SwiftNIO SSH), SwiftTerm 1.20.0, NIOSOCKS (swift-nio-extras), Security (keychain), CryptoKit.

**Spec:** `docs/superpowers/specs/2026-10-20-ssh-tabs-design.md`

## Global Constraints

- Packages pinned `exactVersion`: Citadel `0.12.1`, SwiftTerm `1.20.0`; swift-nio-extras at whatever Citadel resolves (add the product `NIOSOCKS` only to the iPhone target).
- Mac target compiles all of `Shared/`; the iPhone target lists `../Shared/SSH` in `mobile/project.yml` sources.
- Tab URL scheme: `unibrowser-ssh`, host = lowercase host UUID.
- Keychain service for secrets: `app.unibrowser.ssh`, account = host UUID string.
- Files in `URL.applicationSupportDirectory/UniBrowser/`: `ssh-hosts.json`, `known-hosts.json`, `ssh-history/<host-id>.json`, `ssh-commands/<host-id>.json`.
- Tombstone lifetime 30 days (reuse `BookmarkMerge.tombstoneLifetime`).
- Connect timeout 15 s; keepalive every 30 s; PTY term `xterm-256color`; default port 22.
- Suggestions: max 8; history 2000 lines per host, lines starting with a space not saved; command list cached 24 h; directory listing cached 10 s.
- Editor opens files ≤ 5 MB that decode as UTF-8; save writes `<name>.unibrowser-tmp` then renames over the original keeping its permissions.
- iPhone via-Mac SOCKS: `127.0.0.1:47801` (`MacRelay.localProxyPort`).
- ALPN `unibrowser/via-mac/3`; `/2` and `/1` become legacy (told to update).
- All user-facing text in Russian, exact strings as in the spec where it gives them.
- No `Co-Authored-By` or AI mentions in commits.
- Each check script runs the way the README documents its siblings (`swiftc -parse-as-library … && /tmp/<name>`); checks that need Citadel are SwiftPM packages under `scripts/` that symlink the Shared sources.

## Review Focus

1. **Host deleted while its tab is open or synced from the other side**: the tab shows «Сервер удалён из хранилища», never crashes or connects with stale secrets. Test in Task 5.
2. **Password prompt inside the shell (`sudo`, `passwd`)**: echo is off, so no suggestions appear and typed secrets never reach the command history. Test in Task 8.
3. **A connection that drops while transfers or the editor are busy**: the queue items fail with «Повторить», and the editor keeps the unsaved text and says the save failed. Test in Task 7.
4. **The same host edited on both devices while apart**: one version wins on both, and secrets come from the same winner (no password from A with the address from B). Test in Task 1.
5. **Non-ASCII and spaces in remote file names, and multi-byte UTF-8 split across PTY reads**: listing, rename, download and suggestions keep names intact, and the terminal shows no mojibake. Test in Task 7 (names) and Task 4 (feed bytes, not strings).
